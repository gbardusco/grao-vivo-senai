# Conceito Visual 02 — Meio — Carrossel 4 Cards Ancoragem

> [!QUOTE] Fonte — `Atividade_3_...docx:32`
> `c) descrever, com apoio de IA, o conceito visual de cada postagem (composição, cores, elemento sensorial);` — ver `[[peca-02-meio-reciprocidade-ancoragem|Peça 02]]`

## Composição

| Card | Conteúdo | Visual |
|---|---|---|
| **1** | `De R$55 por R$45` (âncora riscada) | R$55 cinza riscado → R$45 Gold grande, fundo Creme |
| **2** | `Fresco vs Industrial` comparativo | Esquerda macro grãos Vale (nítido, Caramelo) vs direita pacote mercado desfocado cinza |
| **3** | `Kit 3×50g frete grátis` | Kit 3 sachês kraft + laço Gold, foto top-down |
| **4** | `WhatsApp <2min` CTA | Mockup WhatsApp “Ana, seu café é o Médio” + selo Vale |

## Cores

- **Creme #F5EFE6** — fundo 4 cards
- **Caramelo #D5A373** — grãos Vale destaque
- **Gold #C9A86A** — preço R$45 + CTA
- **Vale #2E4A3A** — selo “da nossa terra”

## Elemento Sensorial

> [!INFO] Sensorial tátil/visual
> **Tátil sugerido:** textura papel kraft do kit + macro grãos com gotas de óleo (close nítido) — ativa tato por visão. Card 2 com contraste fresco (brilho) vs industrial (opaco).
